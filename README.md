# customer-churn-analysis-project
Built an end-to-end Customer Churn Prediction system in Python using Pandas and Scikit-learn on 5,000 cleaned telecom records. Engineered 3 domain features and trained class-weighted models to handle imbalance, selecting Logistic Regression (0.77 Recall, 0.82 ROC-AUC) to flag at-risk subscribers and guide retention strategies.
